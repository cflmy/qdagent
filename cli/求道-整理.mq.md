# main

**query = > sys.env_get name="QDAGENT_QUERY"**
1. not `query`
  **query = "求道"**
**limit_s = > sys.env_get name="QDAGENT_LIMIT"**
1. not `limit_s`
  **limit_s = "20"**
**limit = > int value=`limit_s`**
**mode = > sys.env_get name="QDAGENT_ORG_MODE"**
1. not `mode`
  **mode = "full"**
**out = > api.organize query=`query` limit=`limit` mode=`mode`**
**raw = > json.stringify value=`out`**
> print text=`raw`
*raw*
