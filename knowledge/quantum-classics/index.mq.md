# 从可追溯的论文开始

本目录先复现 Shor 的完整小规模求阶与因子分解，再逐份扩展经典量子算法。每个知识工程以 index.mq.md 为入口，普通函数兼作使用说明、工具和验证边界；论文下载、参考源码与实际实现分别标识。当前已实现的是 Shor，Grover 的论文与源码仅作为候选材料保留在实际任务工作区。

| 材料 | 用途 |
|---|---|
| [Shor 扩展论文](https://arxiv.org/abs/quant-ph/9508027) | 当前知识的数学来源 |
| [Grover 搜索论文](https://arxiv.org/abs/quant-ph/9605043) | 后续编译候选，尚未复现 |
| [固定来源与许可证](shor/sources.mq.md) | 原件摘要、源码提交与使用边界 |
| [实验与验收记录](shor/reproduction.mq.md) | 实际观测、失败分支与验证范围 |

## reproduce_shor

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| input | map | None | n、a、q、u；完整范围见 Shor 入口 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | 六段实际结果，含测量与重试原因 |

Use `input`=None。

直接调用本函数即可进入 Shor 工程的真实实现，不需要读取一个外部工具注册表，也不需要执行下载的 Python。默认输入为十五、底数二和零点三的测量分位数，控制宽度按论文精度选择为二百五十六；二十一使用五百一十二。结果保留从经典预处理到因子校验的每一步，方便人类和智能体继续解释或引用。

这里执行的是经典处理器上的量子态模拟。它保留模幂双寄存器纠缠态、完整复振幅逆傅里叶变换、实际概率测量与连分数候选验证，没有先用经典求阶器算出答案。规模预算为 n 不超过二十一、控制基态数不超过五百一十二，不能借教学成功宣称获得量子加速。失败的相位、无效参数和经典路线都有明确返回，不自动补出一个预期因子。

开发时按主方案的函数段分工，运行依赖由入口明确连通。来源原件、独立冻结案例和用户审阅记录由实际知识编译任务保存；本目录是可维护的源工程，不通过源码中一句“通过”替代私有知识发布门禁。需要升级算法、扩大输入预算或执行外部实现时，应重新声明范围并验证，不能静默授予进程或网络权限。

完成各段真实计算后，此时直接返回*shor_experiment.run(input=`input`)*。
