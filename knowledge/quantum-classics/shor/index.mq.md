这是一份可以直接阅读、也可以复现实验的中文导读，沿用 Shor 扩展论文七节的顺序。先说明量子计算能改变什么，再建立可逆模幂与傅里叶变换，最后理解它们怎样给出整数的因子。原论文的完整标题是《量子计算机上的质因数分解与离散对数的多项式时间算法》。

正文中的公式采用论文的记号：n 是待分解的整数，x 是选定的底数，a 是叠加态中的指数，c 是测得的频率。附录的实验接口沿用旧参数名 a 表示底数，并以 y 返回 c；例如 n=15、x=2 对应输入 n=15、a=2。第一次阅读只需记住十五和二这两个数，其他符号会在用到时解释。

[阅读原论文 PDF](uploads/Shor-1996-quant-ph-9508027v2.pdf)；[核对版本与来源](sources.mq.md)。本文是按其论证顺序重新讲解，不是逐句翻译；可执行实验实现质因数分解，离散对数部分保留原理推导与手算例。

# 引言

本节关注：为什么这个问题值得重新考虑。

把两个整数相乘很容易，反过来从乘积找出因子却可能困难。例如知道十五的因子是三和五之后，只需做一次乘法便能确认；如果只给一个很长的整数，寻找因子所需的工作可能大得多。讨论算法快慢时，输入长度是这个整数的二进制位数 L，而不是整数 n 本身。一个需要枚举到 n 的算法，依然可能对 L 呈指数增长。

论文关心两个数论问题：质因数分解，以及稍后介绍的离散对数。它没有证明这些问题在经典计算机上一定不能高效解决；它给出的是另一项正面结果——在量子计算模型中，可以用相对于输入位数为多项式的步骤求解它们。

这里的关键并不是“同时算出许多答案，然后全部读出来”。量子测量不允许这样做。算法必须让正确的信息在测量概率中显现出来：先把难题改写成一个带有规律的函数，再用干涉把这种规律转化为能够观察的频率。

对因子分解，这个中间问题是**求阶**。选择与 n 互素的 x，寻找最小的正整数 r，使得 $$x^r\equiv1\pmod n.$$

这个 r 叫作 x 模 n 的阶。为什么找到 r 就可能得到因子，要等到第五节用平方差解释。现在只需带着一个问题往下读：**怎样在不逐个尝试 r 的情况下，知道模幂函数的周期？**

# 量子计算

本节关注：振幅、测量与干涉。

一个量子比特有两个计算基态，记作 \\(|0\rangle\\) 与 \\(|1\rangle\\)。一般的纯态可以写成 $$|\psi\rangle=\alpha|0\rangle+\beta|1\rangle,\qquad|\alpha|^2+|\beta|^2=1.$$

这里的 α、β 是复数振幅。测量后得到零或一，其概率分别是振幅的模平方。多个量子比特组成的寄存器也遵循同一规则，只是基态由二进制串编号： $$|\psi\rangle=\sum_a\alpha_a|a\rangle,\qquad\sum_a|\alpha_a|^2=1.$$

因此，用 L 个量子比特描述的态可以含有 \\(2^L\\) 个振幅，但一次测量仍只给出一个基态。这解释了为什么叠加本身还不够：如果最后只是随便读出一个函数值，我们并没有解决原来的难题。

还需要**相位**。两个态即使在当前测量基下给出相同概率，也可能在后续运算中表现不同。例如 $$|+\rangle=\frac{|0\rangle+|1\rangle}{\sqrt2}, \qquad |-\rangle=\frac{|0\rangle-|1\rangle}{\sqrt2}.$$

直接测量它们，零和一都各占一半。施加 Hadamard 变换以后，前者变成 \\(|0\rangle\\)，后者变成 \\(|1\rangle\\)。相对的正负号改变了干涉，于是原本看不见的区别成为确定的测量结果。

量子门用保持长度的酉变换描述。它们可以改变相位、叠加和寄存器之间的关联，却必须保持总概率为一。后面出现的模幂运算和傅里叶变换，都必须以这样的变换实现。

另一个重要概念是**纠缠**。考虑两个寄存器：如果不同的 a 对应不同的函数值，它们会形成 $$\sum_a\alpha_a|a\rangle|f(a)\rangle.$$

不能把这个态理解为两个互不关联的列表。计算第一个寄存器的测量概率时，同一个目标值对应的路径仍能相干叠加，不同目标值则是正交的。后面的周期峰正是从这种“哪些路径仍不可区分”的结构中产生的。

# 可逆逻辑与模幂

本节关注：怎样把一个经典函数放进量子计算。

普通程序经常覆盖旧值。例如把若干不同的输入都改写为同一个输出，就无法从结果恢复输入。酉变换却必须可逆，因此不能直接把一般函数写成 \\(|a\rangle\mapsto|f(a)\rangle\\)。

一种办法是保留输入，使用另一个寄存器保存结果： $$U_f:|a\rangle|b\rangle\longmapsto|a\rangle|b\oplus f(a)\rangle.$$

当第二个寄存器从零开始时，我们得到 \\(|a\rangle|f(a)\rangle\\)。保留 a 并不是多余的记录；它使整个计算成为一一对应的变换。论文用可逆逻辑门说明，经典计算可以嵌入这样的可逆过程。计算中还需要辅助比特，最后应反向清除无用的中间信息，否则它们可能保留能够区分路径的信息，妨碍后续干涉。

我们需要的函数是 $$f(a)=x^a\bmod n.$$

它不必通过乘 x 共 a 次来计算。把 a 写成二进制，先用重复平方得到 \\(x,x^2,x^4,\ldots\pmod n\\)，再按 a 的二进制位选择相应的模乘。量子版本把这些乘法变成受控制的可逆运算；真正需要控制的是指数的位数，而不是 a 的数值大小。

现在把第一寄存器准备为 q 项的均匀叠加，第二寄存器用于接收模幂。计算后的联合态为 $$|\Psi\rangle=\frac1{\sqrt q}\sum_{a=0}^{q-1}|a\rangle|x^a\bmod n\rangle.$$

以 n=15、x=2 为例，目标寄存器中的模幂值依次是一、二、四、八，然后重复。我们此时看见的，是函数值每隔四项重现的结构；还没有通过测量得知“周期等于四”。

[查看模幂态的可调用接口](unit_oracle)。数值实现保存每个 a 对应的目标基底，并约定它的初始振幅均为 \\(1/\sqrt q\\)。这种稀疏表示省去零振幅，仍能恢复同一个联合态。

# 量子傅里叶变换

本节关注：把重复的间隔变成频率。

傅里叶变换的作用，可以理解为询问：“这个序列中，哪些频率能使重复出现的部分保持相位一致？”论文定义 $$A_q|a\rangle=\frac1{\sqrt q} \sum_{c=0}^{q-1}\exp\!\left(\frac{2\pi iac}{q}\right)|c\rangle.$$

变换前的 a 和变换后的 c 都是基态的整数编号。每个输入会向每个输出贡献一个旋转相位，最后把振幅相加。相位接近一致时相长干涉；相位绕一圈彼此抵消时，得到那个输出的概率就很小。

为什么它能找到周期？设第二个寄存器暂时固定为某个值 \\(x^k\bmod n\\)。第一寄存器中仍可能的指数具有 $$k,\ k+r,\ k+2r,\ \ldots$$

这样的等间隔。对输出 c，这些项的相位差是 \\(2\pi rc/q\\)。当 \\(rc/q\\) 接近整数时，相邻项几乎同向，振幅不会相互抵消。因此，显著概率会出现在 $$\frac cq\approx\frac sr,\qquad s=0,1,\ldots,r-1$$

附近。我们没有直接读出 r，而是读到一个与 \\(s/r\\) 接近的有理数。

如果 r 恰好整除 q，峰的位置特别清楚。十五的例子取 q=256、r=4，频率峰位于 c=0、64、128、192，每个位置的概率为四分之一。对二十一、底数二，周期为六，六不整除 512，峰附近便会出现分布在多个整数位置上的概率，不能把图画成六个手工指定的点。

为了计算这些概率，必须先对每一个目标值内部的路径求振幅和，再把不同目标值的概率相加。完整表达式是 $$P(c)=\frac1{q^2}\sum_z \left|\sum_{\substack{0\le a<q\\x^a\bmod n=z}} \exp\!\left(\frac{2\pi iac}{q}\right)\right|^2.$$

内层先相干求和，外层才取不同目标基底的概率和。把模平方移到内层，或者把不同 z 的振幅先混在一起，都会改变物理含义。

论文还需要说明：当 q 是一个很大的二次幂时，变换不能靠逐项展开整个矩阵来实现。令 \\(q=2^\ell\\)，利用二进制展开，可以把 \\(A_q\\) 分解为 Hadamard 门、受控相位旋转和位序交换，所需门数为 \\(\ell\\) 的多项式。**矩阵很大**与**电路必须很长**并不是同一回事。

[查看完整概率分布的可调用接口](unit_fourier)。现有模拟使用负号的逆变换；对这里初始系数为实数的模幂态，它得到共轭的振幅，因而给出相同的测量概率。数学公式沿用原文的正号约定，程序不会因此改变峰的位置或因子后处理。

# 质因数分解

本节关注：从周期走回整数的因子。

现在回到引言的问题。先排除偶数、完全幂等经典方法已经能处理的情形，再选底数 x。如果 \\(\gcd(x,n)>1\\)，我们已经直接得到一个因子；否则才进入求阶。

假设得到一个偶数周期 r，令 \\(z=x^{r/2}\bmod n\\)。因为 \\(x^r\equiv1\pmod n\\)，有 $$(z-1)(z+1)\equiv0\pmod n.$$

若 z 既不是一，也不是负一，那么这个平方差可能把 n 的不同质因子分到两侧。计算 $$d_-=\gcd(z-1,n),\qquad d_+=\gcd(z+1,n)$$

即可提取非平凡因子。最大公因数仍由经典的欧几里得算法计算；量子部分负责提供难以取得的周期信息。

**第一步：给相位足够的精度。** 论文选择二次幂 q，使 \\(n^2\le q<2n^2\\)。第一寄存器包含零至 q 减一的所有指数，不是只挑几个有利于答案的样本。n=15 时取 q=256；n=21 时取 q=512。

**第二步：准备模幂态并做傅里叶变换。** 这正是前两节建立的计算。实际测量给出一个整数 c，接下来交回经典计算机处理。观察第二寄存器可以帮助推导；只关心 c 时，也可以直接对联合态计算它的边缘分布，不必把某个目标值手工挑出来。

**第三步：用连分数恢复分母。** 对合适的测量结果，\\(c/q\\) 足够接近某个 \\(s/r\\)。当 $$\left|\frac cq-\frac sr\right|<\frac1{2r^2}$$

且 s 与 r 互素时，\\(s/r\\) 会出现在 \\(c/q\\) 的连分数收敛分数中。这使恢复周期成为对少量数学候选的检查，而不是从一到 n 穷举所有可能的阶。

**第四步：验证候选并提取因子。** 对得到的分母 t，实际检查 \\(x^t\bmod n\\) 是否等于一。通过后还要检查偶数周期和平凡平方根，再取最大公因数；最后用乘积验证返回的因子。

为什么这种尝试值得重复？对已经排除完全幂的奇合数 n，设它至少含两个不同的质因子。在与 n 互素的底数中随机选择 x，得到偶数阶且不落入平凡平方根的概率至少为二分之一。这是从求阶归约到因子分解的成功保证。另一方面，测量并非总能给出与 r 互素的分子；论文对有用频率的概率作下界分析，结合可重复尝试，才得到按输入位数计的多项式时间结论。一个成功的小例子本身不能代替这层概率论证。

十五的例子贯穿这四步：选 x=2，若测到 c=64，则 \\(c/q=64/256=1/4\\)，连分数给出分母四。验证 \\(2^4\bmod15=1\\)，再算 \\(z=2^2\bmod15=4\\)，于是 \\(\gcd(3,15)=3\\)、\\(\gcd(5,15)=5\\)。

一次测量并不保证成功。若 c=0，零相位没有给出周期；若 c=128，分数约成二分之一，分母二不能通过 \\(2^2\bmod15=1\\) 的检查。后一种情况丢失了完整分母，因为对应的分子和原周期有公因数。它们都是需要重试的正常结果，不应该从实验记录中删去。

这里的模拟每次只做一次明确的测量。输入 u 表示零至一之间的分位数，使同一次测量可以重放；改变 u 相当于选择新的抽样位置。它不会看到后处理失败就悄悄重新抽样。真实的量子算法还需要随机选择底数，并结合这些成功概率进行重复。

若 r 是最小阶且为偶数，\\(x^{r/2}\equiv1\\) 本来不可能成立；本实验的连分数后处理只验证候选是一个周期，因此仍显式排除 \\(z=\pm1\\)。这也是“一个候选通过模幂检查”与“已经证明它是最小阶”的区别。

至此，可以[运行完整的小规模分解实验](run())。你将得到从前置检查、联合态、概率分布、实际测量到周期和因子的全部中间结果；正文里的每一步都能与它对应起来。

# 离散对数

本节关注：同样的思想怎样发现二维结构。

因子分解并不是论文的全部。给一个素数 p、乘法群的生成元 g，以及非零剩余类 x，离散对数要求找到 r，使 $$g^r\equiv x\pmod p,\qquad0\le r<p-1.$$

例如 p=7、g=3、x=2 时，答案为 r=2，因为 \\(3^2\bmod7=2\\)。知道答案后验证很容易；困难的是在大的群里找到这个指数。

设 \\(m=p-1\\)。论文用三个寄存器，先在前两个寄存器中均匀叠加 \\(0\le a,b<m\\)，再在第三个寄存器计算 \\(g^a x^{-b}\bmod p\\)。得到 $$|\Phi\rangle=\frac1m\sum_{a,b=0}^{m-1} |a,b,g^a x^{-b}\bmod p\rangle.$$

因为 \\(x=g^r\\)，第三个寄存器实际上保存 \\(g^{a-rb}\\)。若它的值为 \\(g^k\\)，前两个寄存器中相关的点满足 $$a-rb\equiv k\pmod m.$$

因子分解给出一维的等间隔结构；这里给出的则是二维指数平面上的平行关系。算法对前两个寄存器分别做傅里叶变换，让这种关系在频率空间显现。

为了看清原因，先暂时把傅里叶变换的长度理想化为 m。沿着 \\(a=k+rb\\) 求相位和，可以写出 $$\sum_{b=0}^{m-1} \exp\!\left(\frac{2\pi i}{m}\bigl(kc+b(rc+d)\bigr)\right).$$

如果 \\(rc+d\not\equiv0\pmod m\\)，各项会抵消；不抵消的频率满足 $$rc+d\equiv0\pmod m.$$

当 c 与 m 互素时，我们便能从一次这样的关系恢复 \\(r\equiv-dc^{-1}\pmod m\\)。不互素时，关系可能不足以唯一确定 r，需要更多信息，不能直接对一个不存在逆元的数做除法。

继续看 p=7 的手算例：m=6、r=2。如果频率关系给出 c=1、d=4，那么 \\(2c+d=6\equiv0\pmod6\\)，也就得到 \\(r=-4\equiv2\pmod6\\)。

这段理想化推导用来解释结构，不是把原文的实现偷偷换成另一个算法。原文实际选择满足 \\(p<q<2p\\) 的二次幂 q，在 q 维空间做变换，并分析频率近似和截断误差。当前可调用实验覆盖前一节的因子分解；本节提供离散对数算法的数学导读与手算核对，没有把三寄存器求解器宣称为已经实现。

# 讨论与开放问题

本节关注：复杂度结论与物理实现之间还有什么。

算法的复杂度以输入位数衡量。量子傅里叶变换可以由多项式数量的小门构成，模幂也可以通过可逆算术实现；在这些计算之外，连分数、最大公因数和候选验证仍是经典的多项式时间后处理。这里没有要求把所有工作都搬到量子设备上。

这份结论并不意味着经典计算机模拟上述量子态也会同样高效。显式保存许多振幅的模拟器，其资源会随着寄存器增长而迅速增加。本文实验限制 n≤21、q≤512，是为了能在普通计算机上看见完整的干涉与测量过程，不代表已经获得量子加速。

论文最后讨论门精度、退相干、误差控制与更多量子算法的可能性。这些问题属于把数学计算模型变成物理机器所面临的困难；算法的存在与工程上能可靠执行很长的电路，是两个不同的问题。这里按原文的历史位置说明这些讨论，不把当时的开放问题直接当作今天的研究结论。

贯穿全文的思想可以回到一句具体的话：**先把数论问题变成规律，再用可逆计算和傅里叶干涉把规律变成可测的概率，最后用经典数学读出答案。** 因子分解与离散对数共享这一思路，但各自的隐藏结构和后处理仍需要单独推导。

| input | map | dependencies.preflight 是前置检查的完整返回 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | n、a、q、powers；非量子路径返回 skipped |

Use `input`。

本函数对应第三节的模幂联合态。powers 按控制基底从零开始排列，配合每项同样的初始振幅，可重建整个稀疏联合态；列表中的重复值尚未被解释成一个已知周期。它不从重复位置提前查出答案，而是交给下一步相位变换。建立该态之后，得到*[模幂演化的真实结果](engine.unit_oracle(input=`input`))*。

## unit_fourier

| 参数 | 类型 | 说明 |
|---|---|---|
| input | map | dependencies.oracle 是模幂态的完整返回 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | 自然序号的 probabilities、normalization 与 normalization_ok |

Use `input`。

本函数对应第四节的完整干涉计算。它先在相同目标基底内求复振幅和，再对目标寄存器取偏迹，保留每个整数频率位置的概率。除了可以看见的高峰，零项和旁瓣也在返回中；检查归一化不会把它们删除。由此得到的*[实际测量分布](engine.unit_fourier(input=`input`))*，才是下一步选择测量值的依据。

## unit_measurement

| 参数 | 类型 | 说明 |
|---|---|---|
| input | map | dependencies 包含 preflight 和 fourier，前者给出 u，后者给出完整分布 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | measured 状态、实际 y、q 和该位置的概率 |

Use `input`。

本函数按第四、第五节的测量分布选择一次观察。u 指定累积概率中的位置，区间左闭右开；恰在边界上时进入下一个区间，零概率位置不会被选中。选择之后不再依据后处理能否成功重抽，因而零相位也会被如实保留。我们取得这次输入对应的*[一次真实测量](engine.unit_measurement(input=`input`))*。

## unit_period

| 参数 | 类型 | 说明 |
|---|---|---|
| input | map | dependencies 包含 preflight 与 measurement，给出 n、a、y、q |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | 验证通过的周期 r 与 checked，或带原因的 retry |

Use `input`。

本函数把第五节的有理数近似变成实际候选检查。它只尝试连分数产生的分母，不逐个枚举所有阶，也不为了让约分相位成功而偷偷尝试所有倍数。checked 保留本次真正检查过的分母；没有获得足够信息时返回明确的重试。最终得到*[由测量恢复的周期结果](engine.unit_period(input=`input`))*。

## unit_factors

| 参数 | 类型 | 说明 |
|---|---|---|
| input | map | dependencies 包含 preflight 与 period |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | 升序的因子对及实际路线，或 invalid、retry 与原因 |

Use `input`。

本函数完成第五节的平方差归约。对量子求阶路径，检查偶周期与非平凡平方根，再计算最大公因数并核对乘积；对经典预处理已经取得的因子，明确保留 classical 路线。失败不会被另一个底数的答案替换。经过这些检查以后，我们便得到所需的*[因子提取结果](engine.unit_factors(input=`input`))*。
