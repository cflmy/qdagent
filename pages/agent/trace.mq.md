公开展示实际阶段、命名参数、marqdo call 参数向量、退出与结果。接口实际返回的思考文本作为阅读内容单独呈现，没有返回就不显示。卡片身份来自事件序号，轮询只修改叶节点，折叠状态由稳定容器保留。

## format

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| value | any | required | 实际记录值 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 适合阅读的 JSON 或普通文字 |

Use `value`。已有文字直接阅读，记录则序列化显示；所有内容再交给原生 pre 元素转义。工具返回中的标签不会变成页面逻辑，显示结果与执行结果仍有独立边界。

1. `value` == None
  Return *"暂无结果"*.
Return *[保留结构化事实](json.stringify(value=`value`, indent=2))*.

## card

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| event | map | required | 真实开始事件 |
| finished | any | None | 相同 span 的真实结束事件 |
| terminal | bool | False | 作业已经终止 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 稳定卡片、状态与结果子区域 |

Use `event`, `finished`=None and `terminal`=False。开始不代表成功，结束才提供实际状态和耗时。取消时未收到结束事件的卡片显示已中断，不能保留假运行动画。详情使用原生按钮与区域，点击只展开已记录的事实，不触发工具。

The card has a stable outer id derived from the start sequence. The heading contains a native button and a separate status label. Its detail region contains two leaf blocks: the actual input and the actual result with call evidence. The details region starts collapsed; a click changes its own visibility class. The status and output have their own ids so later polling can update those leaves without replacing the details container.

A matching finish event determines success, failure and duration. Until then, a nonterminal task is genuinely running. If the overall job has ended without a finish for this span, the card is interrupted: do not leave its pulse running forever or fabricate a successful duration. Cancellation is visible as a separate fact, while any completed operation retains its own original result.

Structured values are rendered as indented JSON in native pre elements. They remain text, even if a tool returns angle brackets, a script tag or a URL. The displayed argv is evidence of the call that actually ran, not an executable copy button. Long records wrap and scroll inside a bounded area instead of stretching the reading page into an unreadable line.

The output record contains both a CSS state and a readable status string. The client should apply these to an existing card and append only a sequence it has not seen. Replacing the entire timeline would lose the user's expanded state and reading position. This function supplies the initial shell and current leaf values so that the browser can preserve those stable DOM nodes.

Provider thinking and the normalized decision have separate leaf targets. The thought body uses the existing safe Markdown renderer, so headings, emphasis and code are readable while raw HTML does not become a script. No thought text is generated by this projection. When the response arrives after a user has opened the running card, only the thought leaf is replaced; the parent details class and focus remain intact.

The button begins with aria-expanded=false and carries only the event sequence as data-id. A model decision uses the same delegated click contract as a tool step. Provider text is not permission to run an operation, and displaying it does not add a successful tool receipt.

结束记录可以是文本、数字、列表或结构化对象。只有对象才读取可选的 decision 和 thinking 字段；其他结果原样格式化，不能让普通任务结束文字因为模型投影而无法恢复。

We **seq = access(`event`, "seq")** and **status = access(`event`, "status")**.
We **output = "等待实际结果"** and **elapsed = ""** and **thinking = ""**.
1. `terminal` and `status` == "running"
  We **status = "interrupted"** and **output = "作业已结束；这个阶段没有完成记录，请检查已产生的效果。"**.
1. `finished`
  We **status = access(`finished`, "status")**.
  We **record = access(`finished`,"details")**.
  We **record_json = json.stringify(value=`record`)**.
  1. text.starts_with(text=`record_json`, prefix="{")
    We **thinking = json.get(value=`record`, key="thinking")**.
    1. not `thinking`
      We **thinking = ""**.
    We **decision = json.get(value=`record`, key="decision")**.
    1. `decision`
      We **record = `decision`**.
    2. `thinking` != ""
      We **record = table.delete(map=`record`, key="thinking")**.
  We **output = [实际结果可读化](format(value=`record`))**.
  We **duration = access(`finished`, "at_ms") - access(`event`, "at_ms")**.
  We **elapsed = str(`duration`) + " ms"**.
We **status_text = `status` + " · " + `elapsed`**.
We **prefix = "qd-event-" + str(`seq`)**.
We **button_attrs = table.put(in=None, at="data-id", value=str(`seq`))**.
We **button_attrs = table.put(in=`button_attrs`, at="type", value="button")**.
We **button_attrs = table.put(in=`button_attrs`, at="aria-expanded", value="false")**.
We **button = [实际点击使用 data-id](component.element(kind="button", value=access(`event`,"title"), attrs=`button_attrs`, style="qd-trace-toggle"))**.
We **badge = [真实阶段标签](ui.text_node(text=`status_text`, id=(`prefix` + "-status"), style="qd-stage-status"))**.
We **header = [最小标题布局](ui.region(children=table.concat(a=`button`, b=`badge`), kind="header", style="qd-trace-heading"))**.
We **input_label = [说明参数来源](ui.text_node(text="实际输入", style="qd-detail-label"))**.
We **input = [原生转义真实参数](component.element(kind="pre", value=format(value=access(`event`, "details")), style="qd-code"))**.
We **output_label = [说明结果来源](ui.text_node(text="实际结果与调用证据", style="qd-detail-label"))**.
We **output_node = [结果子节点稳定更新](component.element(kind="pre", value=`output`, attrs=table.put(in=None, at="id", value=(`prefix` + "-output")), style="qd-code"))**.
We **thought_nodes = table.empty_list()** and **thinking_html = ""**.
1. `thinking` != ""
  We **thought_nodes = ui.text_node(text="模型返回的思考过程", style="qd-detail-label")**.
  We **thought_nodes = table.concat(a=`thought_nodes`, b=component.markdown(text=str(`thinking`), style="qd-thinking-markdown"))**.
  We **thinking_html = ui.render(nodes=`thought_nodes`)**.
We **thought = ui.region(children=`thought_nodes`, id=(`prefix` + "-thinking"), style="qd-thinking")**.
We **details = [内容拆为可读叶节点](ui.region(children=table.concat(a=table.concat(a=`input_label`, b=`input`), b=table.concat(a=`thought`, b=table.concat(a=`output_label`, b=`output_node`))), id=(`prefix` + "-details"), style="qd-trace-details"))**.
We **nodes = [卡片身份不随轮询改变](ui.region(children=table.concat(a=`header`, b=`details`), id=`prefix`, style=("qd-trace-card is-" + `status`)))**.
We **html = [同一 View 组件渲染](ui.render(nodes=`nodes`))**.

We **title = access(`event`,"title")**.

`out` =

| seq | title | status | status_text | output | thinking_html | html |
|---|---|---|---|---|---|---|
| `seq` | `title` | `status` | `status_text` | `output` | `thinking_html` | `html` |

Return *out*.

## cards

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 按真实开始序号排序的独立卡片 |

事件日志是不可变记录，卡片是它的当前投影。一个开始匹配同一 span 的最后结束记录，轮询不会追加伪步骤。没有事件时返回空列表，新会话不会显示别的会话的执行经过。

Start events and finish events have different responsibilities. One start creates one card; a later finish refers back to its span. A finish must not create a duplicate card. The projection matches the last recorded finish for that start and preserves the original chronological order.

The terminal flag comes from the saved job record, not a guess based on a word in the answer. Reading this projection does not advance a tool, contact a model or change the event log. An empty log therefore produces an honest empty timeline.

We **log = [读取真实事件](events.read())**.
We **out = [没有编造的步骤](table.empty_list())**.
We **terminal = False**.
1. fs.exists(path="data/dialogue/proj/job.json")
  We **terminal = json.get(value=fs.read_json(path="data/dialogue/proj/job.json"), key="done")**.
- [每个真实开始对应一张卡片](for log as event)
  1. access(`event`, "kind") != "finish"
    We **finished = None**.
    - [结束记录归属于明确 span](for log as candidate)
      1. access(`candidate`, "kind") == "finish" and access(`candidate`, "span") == access(`event`, "seq")
        We **finished = `candidate`**.
    We **out = [只投影已经发生的事件](table.append(list=`out`, item=card(event=`event`, finished=`finished`, terminal=`terminal`)))**.
Return *out*.


## overview

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| cards | list | required | 真实事件卡片 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 无重复 DOM 身份的事件摘要 |

Use `cards`。检查区和对话读取相同事件，摘要仅展示操作名与真实状态，详细参数仍留在稳定的对话卡片中。不能复制原卡片 HTML，否则会出现重复 id，并让展开操作命中错误节点。摘要不会推断或推进步骤，失败和中断原样保留。

This projection uses the same observed card records as the main conversation timeline. A running pulse means a real stage has started and has no terminal receipt yet. A completed label comes from the recorded finish, never from an assistant sentence. The inspector remains independently scrollable and does not replace a user's expanded details.

The native component renderer escapes all event titles and statuses. A tool output cannot insert a new browser handler. Keeping this list small and separate also avoids dumping an entire JSON transcript into the narrow panel. The user can return to the conversation for the actual arguments, call evidence and results.

We **nodes = table.empty_list()**.
- [每个真实阶段都有独立摘要](for cards as card)
  We **title = ui.text_node(text=access(`card`,"title"),style="qd-activity-title")**.
  We **status = ui.text_node(text=access(`card`,"status_text"),style="qd-activity-status")**.
  We **nodes = table.concat(a=`nodes`,b=ui.region(children=table.concat(a=`title`,b=`status`),style=("qd-activity-item is-" + access(`card`,"status"))))**.
1. table.len(xs=`nodes`) == 0
  We **nodes = ui.text_node(text="任务开始后会显示真实执行过程。",style="qd-empty-note")**.
Return *[摘要不复制原卡片身份](ui.render(nodes=`nodes`))*.
