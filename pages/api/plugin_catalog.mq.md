插件是当前身份可见的真实注册能力，不是聊天内容。入口由已认证同源请求调用，身份始终由宿主覆盖注入；用户不能通过参数指定别人。

# main

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| epoch | any | 0 | 请求切换序号 |
| principal | text | "local" | 认证身份 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 完整注册清单的安全投影 |

Use `epoch`=0 and `principal`="local"。读取不执行模型、不改变权限，也不要求对话已经恢复成功。固有能力和所有登记拓展都从工程服务产生，错误保留真实原因，不用空白面板掩盖。

The source entry and service member are fixed. The browser supplies only the response epoch; the gateway owns the engineering root and trusted principal. This request cannot select a file, native library or arbitrary function. The returned markup is generated by the existing component renderer with escaped registered names and module paths.

We **args = table.put(in=None, at="epoch", value=`epoch`)**.
Return *[独立读取真实能力目录](gateway.invoke(member="plugin_catalog", arguments=`args`, principal=`principal`))*.
