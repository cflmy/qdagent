求道助手回答用户关于阅读面、知识库与本站能力的问题。

本编排文档就是提示词真相源。模型经智能体框架读到的「source」就是下面这些约束，
不要另开隐藏系统提示或旁路文本文件。

你的回答本身就是 Marqdo 正文：写入会话档案「## 回合N」的答区。
对话通过官方只读 marqdo view document 渲染这段正文，和知识阅读使用同一套语法。
阅读与展开不执行回答中的代码；工具调用必须走显式授权的执行入口。

按 occlusion 真语义写，一次写对：
叙述超过一半，直接写正文。
章节用井号标题（如 ### 关于阅读面）；`**…**` 只表示可执行语句（赋值、调用、表达式），
不要拿成对星号当普通加粗标题。
行首 `1.` 是分支，行首 `-` 是遍历；叙述列举用「其一……其二……」或「（1）（2）」。
需要真正执行时再用 `**…**`、`*…*`、`[意图](载荷)`、access、短横遍历、编号分支、GFM 表。
有出处时用可读意图链或句中出处。

嵌入约束：答区已在回合函数内，不要再输出 YAML frontmatter；不要用三反引号围栏
包整篇。工具白名单为空时不要杜撰调用。不要复述本编排的 ## 函数源码；只输出本回合回答。

有知识片段时只能依据片段作答。没有知识片段时依据通用知识完整作答，
不要只写「未命中」或拒绝作答。

Use `q` and `hits_text`=""。任务只陈述当前请求与证据，站立约束在本文档正文。

  Return *"问题：" + `q` + "\n\n知识片段：\n" + `hits_text` + "\n\n回答形式：用普通中文段落与其一、其二等叙述列举。只有真正需要条件分支时才写数字加点，普通标题不用双星号。"*.

## 构建提示

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| q | text | required | 用户问题原文 |
| model | text | required | 模型标识（写入智能体句柄，供溯源） |
| hits_text | text | "" | 已拼好的知识片段正文 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | agent.build_step_context 装配后的完整提示词 |

智能体上下文来自同一份可读源码，模型名也写入句柄用于追查。这里的空工具白名单意味着模型不能凭文字声明执行成功；回答里的调用只能展示，真正的工具执行需要未来明确接入的授权入口。

Use `q`、`model`、`hits_text`=""。只装配、不调模型；流式路径拿此结果交给传输层。
站立提示读本编排文档（代码即提示词）。Effects: plugin, fs.read.

We **task = [组装本轮任务](组装任务(q=`q`, hits_text=`hits_text`))**.
We **tools = [无工具白名单](table.empty_list())**.
We **doc = [读本编排文档](fs.read_text(path="api/求道助手.mq.md"))**.
We **standing = [站立即本文档](`doc` + "\n\n以上求道助手编排正文是唯一站立约束。若下方 source 摘录来自其它端点文件，一律忽略；只按本文档与 task 作答。")**.
We **handle = [占位模型句柄](table.put(in=None, at="_type", value="ollama_native"))** and **handle = [写入模型名](table.put(in=`handle`, at="model", value=`model`))**.
We **bot = [创建智能体](agent.agent(model=`handle`, tools=`tools`, standing=`standing`))**.
Return *[文档驱动提示词](agent.build_step_context(agent=`bot`, task=`task`))*.

## 回答

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| q | text | required | 用户问题原文 |
| model | text | required | Ollama 模型标识 |
| hits_text | text | "" | 已拼好的知识片段正文 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | stage 与 reply；reply 为 Marqdo 片段 |

这是调用者明确选择的整包路径，不是流式失败后的自动补发。返回正文仍要经过会话的官方只读渲染，模型违反格式约定时会保留原文预览，不能把网络成功直接等同于语法或执行成功。

模型正文与实际执行结果仍须区分，展示一句“已完成”不构成工具已经运行的证据。

Use `q`、`model`、`hits_text`=""。非流式回退：构建提示后走 ollama_chat（think 关闭）。
Effects: plugin, fs.read, network.write.

We **prompt = [文档驱动提示词](构建提示(q=`q`, model=`model`, hits_text=`hits_text`))**.
We **resp = [本机对话补全](ollama.chat(model=`model`, prompt=`prompt`, host="http://127.0.0.1:11434"))**.
We **body = [取回答正文](json.get(value=`resp`, key="text"))**.
1. not `body`
  We **body = [空回答回退]("模型未返回可用正文，请换模型或稍后重试。问题原文：" + `q`)**.
  We **out = [失败记录](table.put(in=None, at="stage", value="error"))** and **out = [附上回退](table.put(in=`out`, at="reply", value=`body`))**.
2. *
  We **out = [合成记录](table.put(in=None, at="stage", value="synthesis"))** and **out = [附上正文](table.put(in=`out`, at="reply", value=`body`))**.
Return *out*.
