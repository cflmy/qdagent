# 首页细节对齐

| 材料 | 用途 |
|---|---|
| [首页设计图](home-v3.png) | 内置 imagegen 生成的视觉目标 |
| [完整提示词](home-v3-prompt.txt) | 保留生成约束、配色、尺寸和文案 |
| [浏览器实际截图](home-v3-implemented.png) | 当前原生组件、正式客户端与官方 WASM 的结果 |

先生成设计图，再用同一桌面视口逐轮检查实际页面。默认基准为 1586×992：左栏267、页首46、文稿区496像素。生图本身可能包含尺寸与字体的细小漂移，工程使用这些明确尺寸作为可复现标尺，不把整张位图铺在页面上，也不把生成的示例记录写入用户工作区。

第一轮检查包含对话、计划、工具事件、文件卡片和文稿的完整样例，避免空页面掩盖排版问题。第二轮校正消息字号、计划卡片高度、文件位置和操作图标。第三轮统一边距、隐藏占位滚动条并补齐下载遮罩。最后让文稿在阅读框内滚动，下载与源码操作始终位于稳定底栏，保留窄屏和可调宽度的工程约束。

图标使用当前工程可维护的原生 SVG 遮罩，统一24像素网格与1.5像素线宽；界面本身不需要额外照片或装饰背景。设计图是生成素材，已保存到工程目录，生产界面使用真正的按钮、标签、Markdown与View片段，交互不会落入截图里的静态像素。

# 阅读与操作

| 区域 | 这轮调整 | 行为边界 |
|---|---|---|
| 导航 | 任务卡片、字重、分隔线、悬停与焦点 | 不创建示例任务 |
| 计划 | 步骤和计数保留，目标与验收显式展开 | 不改完成状态 |
| 执行 | 计划之后、交付之前，普通轮询保留节点 | 不重复运行工具 |
| 文件卡片 | 文件类型图标、KB/MB、独立阅读与下载入口 | 只读取已登记产物 |
| 输入栏 | 统一图标、圆角、间距，发送与停止互斥 | 使用既有任务协议 |
| 文稿区 | 文件名、稳定阅读框、源码与下载同一底栏 | Marqdo仍由官方View渲染 |

普通 Markdown 文稿使用紧凑的同构阅读样式，Marqdo 函数和侧注仍属于官方 View 输出。正文可以滚动，工具栏和下载不随长文消失。源码入口显示的是已经接受的源稿，下载不接收新的路径，也不执行内容。参数和返回表格继续作为可读内容保留。

# 恢复状态丢失的修复

完整页面的浏览器验收暴露出效果合并错误：工具卡片首次追加时 set_html 和 set_text 通常为空映射，旧判断把它们当成不存在，外层浅合并便覆盖历史、计划及页首标题。这会造成只有工具卡片出现、对话和工作台仿佛没有加载的现象。

现在两边键只要存在，就合并内部选择器映射。空补丁保留已有内容，同一目标仍允许后者更新，不同目标同时保留。tests/effect-merge.mq.md 直接调用实际客户端函数，覆盖空左侧、空右侧以及明确的目标更新，没有复制第二份产品算法。
