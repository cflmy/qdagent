## handbook

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 实际版式、素材与验证入口 |

| 格式 | 实际布局函数 | 适用内容 |
|---|---|---|
| PPT | cover | 封面题目与副标题 |
| PPT | title_body | 一个主题的短正文 |
| PPT | focus | 关键词或短结论 |
| PPT | two_columns | 有独立标题与正文的左右对比 |
| PPT | quotation | 原文与必填出处 |
| PPT | image_text | 已上传 PNG、替代说明与旁文 |
| Word | report_chapter | 自然跨页的连贯报告 |
| Word | notice | 有边线和底色的提示块 |
| Word | focus | 不凑字的短结论 |
| Word | illustrated | 正文、真实 PNG 和图题 |

每种布局就是一个普通 Marqdo 函数。参数表紧随标题，并说明有效最小字数、原始最大长度、最多行数、每行长度和素材要求；文字预算取决于实际区域、字号与行距，不能共用一份宽松“最多几百字”规则。最小量剔除空白，最大量计入换行。用户原文不可随意修改，选错布局应换布局或重新确认分组，不做填充和静默裁切。

构造结果可放入 Word/PPT create 的内容列表；失败 Result 不可当成内容。生成器重新调用同一构造函数校验全部块，读取并完整解码真实 PNG，核对尺寸、比例与总量，全部通过后才创建目录。不是只有函数构造时才检查，也不能用手工 map 绕过限制。图文图片等比例放入固定区域，不拉伸、不自动裁图。

修改双栏、引文与图文时，用完整布局记录调用 index.mq.md 的 replace_layout；普通正文修改保持原布局字段并重验。派生 body 与字段不同会拒绝，不能源稿已经改了而实际页面还是旧栏内容。源稿保留布局版本及真实图片摘要，旧办公文件始终可用；原图变化后必须明确建立新布局。

实际字号和几何在 drawing、text_pages 与 render 文稿中，静态 XML 在固定声明模板中。更改模板必须同时调整对应预算和边界测试，通过真实 Office 排版与预览；字符约束不能保证所有字体与应用都像素一致。开发规范见 docs/office-layout-contracts.mq.md。

Return *"明确选择布局函数，校验全部内容与真实素材，再写入并实际渲染；不以补字、缩字或裁剪掩盖错误。"*.
