# Theme provenance

QD adaptations reference reveal.js **5.2.1** white, black and beige themes: https://github.com/hakimel/reveal.js/tree/5.2.1/dist/theme . Exact CSS and MIT license are retained in vendor/. These are design sources, not runtime CSS: no remote fonts or template code are loaded. Editable native Office shapes are produced by bounded Marqdo layouts. QD does not claim arbitrary Reveal decks can be imported losslessly. PPTX has native slide transitions; PDF is static; browser content previews use their own accessible motion.
