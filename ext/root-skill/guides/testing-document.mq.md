## handbook

当前只冻结公开文档契约，唯一调用入口是当前手册中的 require_document。不要执行研究，不调用规格里尚未实现的 unit_ 目标，不创建 sample 或 expected 全文。minimum_chars 按明确的最小字数要求填写；未规定时给出合理的有界正文下限并在 rationale 解释。minimum_sources 表示实际访问且在文章中引用的不同来源数量，资料研究需要真实来源，固定用户材料可以为零。

测试角色只看到冻结规格的意图文本，看不到实现、作者输出或开发对话。冻结规则不能跟随实现结果变化。确定性执行器会运行实际函数，再用标准 Markdown 解析和真实来源记录核对返回。结构与可追溯性不证明每个事实正确，不能省略最终用户审阅；主题、受众与内容质量仍需核验。
