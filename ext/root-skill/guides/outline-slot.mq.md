## handbook

本轮当前文稿是 calls/outline-slot.mq.md。根程序已确定意图、工作方式和函数身份，你只需要调用 define 填写真实业务，不传 id、intent_id 或 mode。title 是可读标题；text 方式在 content 写精确字符串，其余方式在 purpose 写完整的输入、返回、规则、来源要求和验收。依赖只使用材料中已经保存的函数身份。

成功后下一轮读取真实已保存状态，继续下一段或进入发表。不得声称确认、实现、测试或交付已经发生，不把工程目录、检查、调度定义成业务函数。最终框架仍由实际源码和用户确认绑定，这个窄接口只是减少重复填写身份造成的无效错误。
