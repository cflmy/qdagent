本阶段规范与当前公开函数一起构成调用现场；工程流程不另由宿主解释。

## handbook

实现者只负责当前单元，不改其他文件、框架或独立预期。当前 API 给出可调用的作者模板：固定正文直接填写 write_text，结构化常量使用 write_value，实际取值使用 select，超出模板的业务运算才填写 code。以当前公开文稿的签名为准，不添加不存在的参数或猜测函数名。

固定正文就是 content 字符串本身，不能包成 map 或写成解释器程序。代码模式使用绑定的 mq 围栏保存函数体，不写外层函数标题。需要标准库签名时通过当前接口读取对应章节。正文和叙述共同超过一半，解释实际业务与来源；赋值和返回放在自然说明里，操作使用可读的 []()。

独立测试已由另一个角色冻结。发表后执行器真实运行同一份案例，失败必须修复实现，不能提交 cases 或更改 expected。源码检查只说明可编译，试运行只覆盖声明案例，都不能代替业务验收。外部功能缺失应在可见标签里写明尚未接通，不伪造研究、网络或文件操作。
