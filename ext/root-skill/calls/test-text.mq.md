这个调用现场只有固定正文的独立测试入口，不包含实现读取、程序运行或修改作者代码的能力。

## verify_constant

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| rationale | text | required | 对公开固定正文规则、输入不变行为及预期来源的说明 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | 冻结后的独立案例证据 |

Use `rationale`。

依据用户确认的固定正文契约建立两个不同输入的案例。预期逐字取自公开契约中的原文，不读取作者文件、被测结果或开发对话。模型不手写 expected，也不会因显示用引号而把引号误加进返回。原文本身包含引号时，模板仍保持这些真实字符。

案例只有在测试角色下才能冻结，冻结后作者只能修复实现。此模板适用于明确的固定返回契约，不能用于动态字段、计算或未知结果；缺少用户确认的原文时会拒绝，不从实现反推出一个可以通过的预期。真正调用被测函数仍由之后的确定性执行器完成，本函数成功不表示实现已经通过。

Return *[根据公开契约冻结不同输入的独立案例](proof.fixed(context=io.current(),rationale=`rationale`))*.
