本规范记录 2026-11-17 的体验修复。任务推进仍由根 Marqdo 文稿负责，界面只呈现真实消息、执行事件、产物与权限，不新增模型动作协议，也不把连接恢复当作业务任务完成。

## conversation

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 执行与产物的展示位置 |

一次回复应有一个清晰的智能体身份。头像放在回复开始处，执行经过、工具观察、回答和本轮产物都属于这次回复的内容区。不得先在头像上方渲染一整段执行过程，再在底部显示一个仿佛与执行无关的回复头像。执行正文使用较小字号，真实错误可以展开，原始协议保持按需查看。过往轮次继续保留查看执行记录的入口。

同一批次的多风格结果直接在对话中展示，允许切换风格、同页比较、翻页、下载和单独大屏打开。预览仍来自真实 PDF，不用背景图片代替实际排版；PPT 原生转场与界面播放动效继续明确区分。正在生成时显示真实变体事件，部分失败保留各自状态。没有产物的对话不插入空画廊，任务中只有文件时也可直接阅读其已有结果。

右侧面板负责文件树和单文件阅读，不再因为检测到变体而自动跳到多方案。用户主动打开某个文件时仍可阅读源码、Office、PDF 和原生 Marqdo View。文稿的关系线与只读行为沿用官方渲染，不改写 View 本身。窗口缩窄时，对话中的对比转为纵向排列，不能把输入框挤出可用区域。

Return *"头像标明回复归属，执行和多结果在对话内呈现，文件树保留精确阅读入口。"*.

## access_design

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 权限与用量界面的设计依据 |

设计图为 docs/design/access-and-usage.png，原始生图提示保存在同目录的可读文稿中。设计沿用米白底、橄榄绿、浅金色描边和衬线标题。桌面弹窗宽度一千零二十四像素，内边距三十二像素，身份、三项用量、默认额度与用户列表有固定的层次；窄屏改为卡片和双列编辑控件，弹窗内部滚动，关闭按钮始终位于标题区。

设计图中的姓名、次数和角色仅用于布局示例，产品必须读取实际身份与额度。管理员不限额时明确标注，不伪造进度条。普通用户显示自己的用量与公共知识规则，审计员能读取管理信息但不能编辑；其他管理权限继续来自统一身份站。用户额度表只使用可读名称，不显示内部长身份码。

保存默认额度与单用户额度分别提交到原有受权接口。正在保存时阻止重复提交，失败保留输入并显示实际提示，成功后重新读取服务端结果。角色刷新仍跳到真实登录，不通过本地设置提权。输入框说明负一和零的真实含义，不能借更好的视觉设计省略降低限额对现有任务的影响。

Return *"按设计的尺寸和层次实现界面，用真实数据与服务端权限填充。"*.

## connection

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 模型故障的定位、恢复与验收 |

这次直接失败的线上运行选择了 builtin-local；对应事件只记录了 provider transport failed。本机原有 Ollama 容器当时已经停止，退出码为零，未发生 OOM，配置仍指向该服务。恢复原容器后，确认其 API 能列出实际 qwen3.5:4b-q4_K_M，并使用工作台进行真实模型请求；没有另行下载或替换模型。

网络传输层分别报告连接拒绝、超时、域名解析、安全连接和连接中断。诊断只包含受控的连接事实，不输出异常中的凭据、请求正文或私有地址。历史通用错误只能说明当时未保存具体原因，界面不能事后编造某次失败的细节。新的连接拒绝提示说明本机服务可能未启动，让用户联系管理员或主动选择其他模型；系统不会静默改用另一个供应商。

暂时网络故障的有限重试仍由 ext/root-skill/runtime/io.mq.md 决定。两次尝试都经过原子额度计量，不能把重试移入 Python 来绕过根流程。恢复服务和请求成功不等于用户确认了意图；真实验收应看到 Marqdo 校验与调用成功，并在需要人工选择时停在等待用户确认。

Return *"恢复实际服务，显示可读连接事实，以真实 Marqdo 调用验证，不伪造业务完成。"*.

## verification

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 本轮实际验收与部署边界 |

传输测试覆盖本机消息原样发送、实际增量输出、公开地址限制和脱敏错误诊断。根文稿测试验证模型接口暂时返回五百零三时有限重试，并继续核对实现者与独立测试者隔离。官方检查器通过了所有构建文稿的语法、契约和每函数叙述比例检查。

浏览器用隔离开发账号运行真实 Qwen，请求成功提交了通过检查的 Marqdo 调用，并进入等待用户确认；没有将提问阶段自动跳过。执行记录位于回复头像后的同一内容区，工具错误、参数预检和恢复依据可展开。另一组浏览器用例读取真正的三种风格 PDF，在对话中切换、并排比较、翻页与大屏打开；右侧没有自动展示多方案。图片预览仍在隔离阅读器中，实际图片尺寸与下载响应安全头均通过检查。旧用例中查找父页面图片元素的定位已改为当前隔离阅读器，未削弱实际解码与响应验证。

普通用户与管理员分别验证了权限页面，默认额度修改可以保存并按服务端结果恢复，手机宽度下弹窗不溢出，关闭操作保持可见。设计截图对照布局检查，截图捕获会跳过短暂入场动画，避免把半透明过渡帧当成最终设计。生图示例不会替代账号的真实姓名、角色、用量和限额。

部署前确认没有活动任务，数据库在线备份保存为数据卷内 pre-conversation-experience-0.15.1.sqlite3，旧镜像标签为 qdagent:pre-experience-0.15.1。更新只替换主服务，远程与本机的运行标识均为 qdagent-conversation-experience-0.15.1。健康与 SQLite 完整性检查通过，任务、消息和模型配置数量保持二十三、四十五、七，原有七九六四端口继续服务。新主容器可以访问真实本机模型。以上证明本轮连接恢复和交互行为，不代表未经审阅的任意复杂任务都能成功。

Return *"已通过实际模型、文稿、浏览器与线上验证；原有数据和确认门禁保留。"*.
