本文定义以后每次开发必须遵循的目标架构。**不是声明全部运行时改造已完成。** Marqdo 的 `.mq.md` 既是可读文档又是可执行 SKILL；`##` 函数就是工具。减少小模型负担意味着减少**每步模型可见的上下文与输出选择**，绝不是削减权限、真实执行或独立验证。

## principle

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 不可违背的开发原则 |

根模型只做当前一步：意图选项、已注册下一层选择，或互不依赖任务拆分。不得要求根模型生成全局计划、加载全部工具、模拟子工具、解释所有实现或输出大量 JSON。只提供当前可用的二到三个选择、当前 `##` 函数契约与事实状态。下一级 SKILL 再读取它需要的资料。提示词、角色指令、修复提示、条件与分派均由 Marqdo 文稿定义，Go 只执行认证、存储、I/O 和事件转发；Python 只允许无策略的模型供应商传输，不得成为第二个 Agent Loop。

使用 Marqdo `ext/ai/flow.mq.md`、`workflow.mq.md`、`context.mq.md`、`lib/subtask.mq.md` 和知识编译能力。不要造另一个工具注册中心、SKILL 语言、模板路由表或正则解析器。所有模型输出都是候选数据，实际函数必须经过官方绑定、宿主权限和真实效果门禁。

Return *"模型决定一步；Marqdo 验证并推进；宿主只处理可信系统边界。"*.

## routing

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 根流程和并行约束 |

新请求为空只询问需要做什么。非空先提供 2～3 个真实不同的短选项及利弊并停止，用户点击或自由输入一次确认。旧请求被恢复时不能重启确认；同一检查点的重复回复幂等，旧版本、其他用户和冲突回复均拒绝。用户取消不进入下层。

确认后只决定一层允许的 SKILL，并传递简短用户意图。不猜测路径，不展开 SKILL 树；候选 ID 由当前宿主授权的已安装 Marqdo 文稿解析，不能凭生成的文本扩权。单任务下发一个子文稿；复合请求拆成各自有目标、必要输入、依赖和预算的任务。相互独立的任务由 Marqdo 原生 `subtask.run_many` 并行；有依赖的按 DAG 分批就绪后才执行。真实子进程状态与退出码要逐项核对，失败和未知副作用不被改成成功，也不盲目自动重试写入。

Return *"确认一次，选择下一层；独立任务并发，有依赖则按图调度。"*.

## context

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 每次模型请求允许的输入 |

根模型默认只看到 **当前用户输入 + 一份关键状态文稿的有界摘录 + 当前唯一函数的参数/返回与短指令 + 本层少量能力摘要**。子模型默认只看到本单元已确认公开职责、必要依赖结果、获准来源的精确片段和当前函数，不带根对话、其他角色实现、工具输出全集或整仓库提示。只读材料按官方 Marqdo 标题/函数与知识锚点定向获取；索引是定位工具而非业务权威。

初始性能目标：根输入不超过 2048 tokens、输出不超过 128 tokens；子任务初始可见现场不超过 4096 tokens。必须用实际 tokenizer 或模型用量计数并记录超预算原因。这些数字是后续需要真实门禁和实验校准的**目标**，当前不声称已经强制执行。必要的长文件、严格规格与事实核对允许分步增量读取，不可静默截断关键约束、猜造遗漏内容或跳过检查来满足 token 限额。模型不知道下一步时，具体请求一个缺少的片段，而非把全量资料重新投喂。

Return *"只看自己的任务、自己的函数和必要证据；缺什么再读什么。"*.

## memory

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 多轮对话的唯一默认关键文稿 |

**每个任务一份 `memory.mq.md`**，位于该任务工作区，采用原生 Markdown 排版，仅含：目标、已确认约束、用户决定、任务与依赖、真实证据索引、未解决问题、下一步。该文稿是**数据**而不是带 `##` 可执行函数的 SKILL。不要保存原始完整聊天、长网页、工具 stdout、未经确认的模型推测、密钥或内部测试内容。下一轮默认只携带这份文稿的有界摘录与最新输入。

用户确认或真实执行证据才允许更新；使用现有工作区身份检查、源 revision/digest CAS、原子写入、并发冲突显式合并。子任务提交自己的可验证收据，根程序合并，不允许子任务用旧版本覆盖他人更新。原始消息、文件、冻结测试和审计仍可单独存储用于回看/验收，**但不再默认注入模型**。改变用户目标必须重新确认，不以记忆文件伪造确认。

现有运行文稿仍交接部分近期历史；这项契约需要后续真实修改 `runtime/prompts.mq.md` 并验收后才能宣布落地。静态例子见 `tests/fixtures/small-model/memory.mq.md`。

Return *"会话只注入一份有版本的关键文稿；历史只供审计而非完整提示。"*.

## evidence

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 证据和失败处理 |

模型输出正确格式 ≠ 调用成功 ≠ 子任务验收 ≠ 用户确认。独立测试者只看冻结的公开职责和契约，不能看实现；真实成功以执行收据、源摘要与业务检查为准。对未知外部写入必须停止并核对结果，不可因恢复自动重做。Lean 证明只覆盖明确建模的语义，不能证明模型理解、联网事实或未建模的副作用。 知识引用、稳定锚点与通过的 proof-deps 审计均不等于已证明；Marqdo 2.9.1 的 compose/replay 只在受限 Lean Int 模型中提供 model_proved，当前版本、依赖闭包与证书必须重核。子任务按需调用知识 SKILL，根模型不加载整份证明报告。开发接口和证明边界见 docs/design/knowledge-proof-integration.md。

必须保留既有 `docs/document-driven-agent.mq.md`、`docs/knowledge-compilation.mq.md` 和 `docs/function-section-concurrency.mq.md` 的安全边界。小模型失败时缩小单步选择、返回准确诊断并保留已成功结果，而非加大提示词、扩大权限、修改独立预期或编造兜底。

Return *"真正完成必须有真实执行和独立证据，不是模型声称完成。"*.

## acceptance

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 可测而非口号式的验收 |

固定测试集必须覆盖：空输入、明确/模糊意图、一次确认、自由输入、重复与冲突回复、刷新恢复、无效 SKILL、不相关任务并发、DAG 依赖等待、部分成功、未知外部效果、原始历史不默认注入、跨用户隔离与记忆并发冲突。以至少一个约 1B 与一个 3B～4B 实际模型，和“全上下文”基线比较端到端正确率、每步决策合法率、首轮/总 token、调用次数、失败恢复和完整证据比例，公开失败样本与置信区间。

本仓新增的无依赖静态检查只防止根入口膨胀与 Python Agent Loop 回退；它不验证上述真实模型行为。实施关口和已知缺口见 `docs/design/small-model-native-agent-rollout.md`，未通过前只能称“设计/静态约束完成”。

Return *"先证明逐步决策与实际效果，再宣称小模型适用。"*.
