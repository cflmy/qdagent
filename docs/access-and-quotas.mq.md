本规范落实身份站公开接入文档 https://id.cflmy.cn/api-docs 中的用户身份规则。用户确认普通账号最多三个未归档任务，智能模型每天五十次实际请求，本机 Qwen 不限额。本文件记录资源授权边界，智能体的阶段和提示继续由根 Marqdo 文稿定义，宿主仅实施身份、事务和进程约束。

## identity

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 角色来源与能力边界 |

登录仍验证 ID Token 的签名、issuer、audience、nonce，并核对 userinfo.sub。角色只来自该次 HTTPS userinfo 的 is_admin 与 admin_role；两者必须相符且角色必须在身份站定义内。super_admin 和 operator 可以维护公共知识和修改用量；auditor 只读管理页，不能创建知识、写回或改额度。普通用户、缺失字段、未知角色和客户端自己传入的角色都不能获得管理权限。邮箱、昵称和首个登录顺序不参与判断。

角色与本次最长八小时的本地会话一同保存，到期不能继续提供管理授权；再次登录会重新取得并覆盖身份站角色。升级前的已有会话保留普通访问，重新登录之后才取得新的角色信息，不借旧会话推断谁是管理员。应用管理页只调整资源限额，不创建另一套身份角色或替用户在身份站提权。开发管理员仅在显式回环开发配置中启用，生产 compose 不包含此配置。

Return *"身份站决定角色，服务端实施授权；审计员保持只读。"*.

## knowledge

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 公共知识的创建、阅读与更新规则 |

新发布知识保存到 data/knowledge/public。所有登录用户可以阅读、下载已发布来源、按明确接口只读运行，并将知识用于自己的任务；匿名请求仍需登录。创建编译任务、发表公共版本和修改共享文稿只允许管理员。页面隐藏入口只是体验，HTTP、Marqdo 和 ABI 各自核对受信身份。普通用户不能通过直接请求准备、发布或显式写回绕过权限。

管理员任务工作区、未发布草稿和交流验收记录不是公共知识目录。历史私有版本不自动搬入公用目录，避免把未审阅材料或对话直接公开；需要共享时由管理员审阅并发表新版本。公开文稿和依赖继续绑定真实摘要与原有冻结案例，不以公开可见代替验证通过。知识详情沿用原生 View，阅读不执行，业务函数只读，写回另有管理员与版本门禁。

Return *"公用知识人人可读，只有管理员创建和更改；任务与审计记录保持隔离。"*.

## limits

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 原子计量、重置与超限后的行为 |

默认三个未归档任务。新建与恢复都通过 SQLite 的同一条条件写入核对名额，并发不能超卖。归档释放名额，归档后的删除遵循原有生命周期。降低限额不会删除已有内容，超额用户仍能查看、归档与使用已有任务；新建和恢复受约束。管理员可以调整普通用户默认值或单用户覆盖，写入保留操作审计；负一表示不限额，零表示停止新增。超级与运维管理员不受普通用户默认配额。

智能模型按北京时间自然日，每次向模型传输层派发前计一项请求尝试；主任务、子智能体、独立测试模型与暂时网络重试统一计量，任务切换、重新登录和并发不会重置计数。一次请求的唯一身份含运行、函数段、角色、轮次与尝试；重复身份不再次派发。计量在真正的运行时模型边界，通过私有请求绑定用户与实际模型配置，前端和模型不能指定别人的计量身份。额度用尽不发供应商请求，不无限重试或自动换模型。

每日零点重置是查询新的日期桶，历史计量不删除。本机 Qwen 3.5 使用四十亿参数的 4B 配置，不受共享智能模型的每日限额；个人自带服务也不消耗平台共享智能模型额度。不限额不代表取消全局并发、进程时限和文件权限。前端显示已用、上限、任务数量和重置时区，调用失败保留真实原因。

管理员可以从受信账户另外开放多个共享模型：智能模型账户里同批配置的其它模型，以及独立共享目录账户里的条目，对外身份都是 shared- 加配置身份。这些条目与智能模型共用同一份每日额度，计量行固定记为共享智能模型，换一个共享条目不会刷新或绕过上限；本机与个人模型不受影响。共享条目的检查器分组只用于把同供应商折叠成一个入口，不改变解析与额度归属，配置身份仍需重新对受信账户校验。

Return *"任务名额与模型请求在实际边界原子核对，子调用和重试共同计量。"*.

## one_function

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 小模型的生成和调试粒度 |

每轮模型只填 act 的正文，宿主提供标题、导入和签名；回复不得重新生成整个可执行文档。准备参数可以调用官方语义图确认的纯函数，每轮最多一个非纯操作，多项操作在执行前整份拒绝，不能先执行前半段。没有新的工具注册表，纯性和参数均由现有文稿的官方 AST 与语义闭包确定。

作者只编写分配到的单个函数体，模板建立参数和返回表。候选必须恰有这一函数，不能带另一个标题、类或邻段实现。每次提交都先官方校验，再仅重跑这个函数的独立冻结案例；已经通过的邻段不重写，失败也不能改预期。模型可显式调试已有单元，错误经验只属于同一角色、契约和接口版本。整体组装由确定性的根文稿完成，不再让模型重写整份工程。

Return *"一次一个操作，一次一个函数；逐段验证后由根文稿整合。"*.

## verification

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 2026-11-17 的实际验证与边界 |

Go 竞态测试覆盖身份站角色、审计员只读、管理员审计、归档恢复和私有模型请求授权。十六次并发新建只获得三个任务，六十四次并发智能请求只获得五十个许可。本机模型不扣共享智能额度；北京时间跨日使用新的计量桶。签名模拟身份站回调验证了 operator 身份，普通用户的直接管理请求均被拒绝。

原生语义测试拒绝同轮两项写操作并保证拒绝前没有副作用；知识真实 CLI 测试证明另一账号能阅读和只读运行公共文稿，但不能发表和写回。根流程、独立测试隔离与暂时网络失败重试通过回归。浏览器分别验证管理员修改额度、普通用户看到公共知识并运行函数、第四个任务被拒绝和手机宽度显示。

隔离普通账号还通过真实共享智能模型完成两轮 Marqdo 调用，保存意图后提问并停在等待用户确认；两次实际请求对应今日用量二、余量四十八，未把等待确认算成完成。部署版本 qdagent-access-control-0.15.0 继续使用 7964，已有任务、消息与模型配置数量保持一致。验证时本机 Ollama 端口未启动，因此 Qwen 的额度逻辑通过测试，其实际模型推理未完成在线回归，不宣称该服务已经可用。

Return *"权限、并发计量、公共只读和单函数执行已验证；本机推理服务仍需启动。"*.
