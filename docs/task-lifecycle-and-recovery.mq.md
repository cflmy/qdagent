本文约束求道后续开发。任务记录属于用户；失败恢复应利用当前可执行文稿与官方绑定能力，不能建立另一套模型动作协议。所有固定模型指令继续只写在 Marqdo 文稿中，宿主负责受限输入输出、认证、存储和事件转发。

## lifecycle

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 任务的归档与删除边界 |

归档保留对话、阶段历史、执行记录与工作区文件，归档列表与工作列表分开显示。选中归档任务后仍能阅读文件和阶段回看，刷新不能无故切换到另一任务。归档不覆盖原有执行状态；恢复只恢复可操作性，不再次运行模型、不重新提交用户操作。

执行中不能归档。归档后的任务不可重命名、上传、发送消息或提交阶段回应，前端显示只读状态，后端同样检查；归档与启动共享同一并发锁，不能仅靠按钮禁用。用户身份与跨站请求检查适用于归档、恢复和删除，不能访问他人的任务或执行记录。

只有归档之后才允许永久删除，并由用户明确二次确认。删除当前任务的工作区、会话目录、消息、运行和事件，不删除其他任务，不沿符号链接清理外部资料。先持久化删除标记，再清理文件和数据库；中断后的清理在服务启动时继续，已经标记删除的任务不再可见。清理尚未完成则诚实返回等待清理，不能宣称资料已经完全消失。

Return *"归档可读可恢复；删除先归档、再确认，并保留中断恢复能力。"*.

## preflight

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 普通函数调用的校验边界 |

模型继续输出普通 Marqdo 调用文稿，使用本轮公开的函数和真实参数。根程序在任何工具执行前检查整份候选，复用官方解析器及外部参数绑定器，拒绝未知函数、越权导入、未知参数、重复参数、缺少必填项与静态可知的类型错误。不建立额外 JSON 工具参数表，不从宿主补充模型提示。

默认表达式和嵌套工具在预检时不执行，避免校验产生副作用。来自先前调用返回的动态值只能检查结构，真实类型仍在 Marqdo 实际调用时复核；页面明确显示“运行时确定”，不能把预检通过当作业务完成。执行前再次核对实际接口源码摘要，拒绝校验与执行版本不一致。

失败候选保存在私有运行审计中。事件同时记录函数、已知参数预览、意图文字、源码版本与实际退出证据。前端的可读视图是这些事实的展示，不是另一份语法解释器或工具路由。当前单元仍须通过冻结规则与用户验收，静态检查不能替代独立测试。

Return *"官方语法与绑定器先检查整份调用，动态值执行时复核，门禁保持独立。"*.

## recovery

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 错误经验、重试与上下文隔离 |

runtime/recovery.mq.md 根据真实失败保存原因、错误代码、有限调用片段与修复依据，最多六项，下一轮最多交接最近两项且总长度受限。缓存身份包含目标、框架、当前规划槽位或函数段、角色与实际接口源码版本。测试者只能看到自己的失败，不能得到作者实现、修复过程或其他单元正文。

经验中的调用是只读数据，不能自动执行。后续一次调用成功只记录“后续成功”，不声称原目标已经完成；例如搜索成功不能把之前访问失败的网址变成已阅读来源。业务门禁继续依据当前状态、来源、源码和冻结案例判断。缓存损坏或不可写时仍交回当次真实错误，披露未保存；相同无效调用连续三次停止的条件不依赖缓存写入。

修复建议、错误分类、暂时网络故障的重试策略全部由 Marqdo 文稿定义。模型请求仅对明确的暂时传输错误至多尝试两次，间隔半秒，每次使用相同授权模型和消息，输出与审计身份分开。鉴权、未知模型、预算及普通程序错误不重试；工具有副作用，不能套用这种自动重试。修订后的候选仍经过整份官方校验。

Return *"错误帮助同一角色修订调用，绝不越权、改测试或伪造业务完成。"*.

## presentation

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 执行经过的可读展示要求 |

执行区直接展示各步骤的简短摘要，校验失败和错误恢复默认展开。参数与静态检查用表格，普通返回值用字段和值，来源保持可点击，文件使用可读名称。错误诊断递归拆除必要传输包装后显示具体原因和位置，不能把多次转义的协议直接当作用户说明。

用户仍可展开实际调用文稿与完整原始协议，后者默认收起。用户主动收起或展开步骤后，流式更新不能覆盖其选择。子智能体内部的模型请求、校验、调用和修复分别展示，角色与轮次共同确定身份，不把测试第一轮与实现第一轮混在一起。模型没有返回单独说明时如实显示，不生成内部思维过程。

Return *"用户能直接看懂发生了什么，也能继续核对实际文稿与原始证据。"*.

## verification

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 本轮验证范围，具体结果见本地测试与交付记录 |

验证覆盖已有数据库迁移、归档恢复、正在执行时拒绝归档、所有者隔离、只读限制、归档后删除及符号链接边界。浏览器通过真实 Go 服务操作一次临时任务，核对上传文件仍可阅读、刷新保持归档选择、恢复没有自动运行、取消删除保留资料及最终删除。

实际 ABI 验证整份候选的后续错误阻止前序写入，缓存受限且不能路径越界。模型网络替身只替代供应商输出，真实根文稿仍执行隔离测试、错误修复与阶段门禁；暂时传输失败的重试保留独立尝试身份。界面测试核对可读参数、动态类型说明、具体失败与后续成功的证明范围。完整回归另包含真实本机模型的用户确认流程。

本轮于 2026-11-16 通过全部文稿的官方语法、契约与每函数叙述比例检查，Rust 十项边界测试、协议二十六项中的二十五项、工作器九项及 Go 竞态检查。协议中一项需要专用外部浏览环境的既有测试按条件跳过，本轮未把跳过计为通过。前端十五个不同用例完成验证，覆盖真实本机模型流程；一处因摘要与详情同时出现而重复匹配的测试选择器修正后，收据与归档四项再次通过。
