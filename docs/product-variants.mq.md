办公风格以可读函数维护，布局继续执行原有内容预算。设计适配自 reveal.js 5.2.1 的 MIT 主题，原 CSS 与许可保存在 ext/office/themes/vendor，运行时不加载远程字体或模板脚本。

## contract

| 返回 | 类型 | 说明 |

| result | text | 多产物开发要求 |

用户在框架确认时选择风格，默认留白画廊、极夜星图、日落编辑部；原有竹影纸笺仍可用。同一批次所有版本消费相同已验证正文，不能让一个风格变体悄悄重写结论。每种布局继续是独立 Marqdo 函数，主题只改变配色、边缘装饰和原生转场，不缩字或绕过预检。

变体由 Marqdo 普通函数并行创建，最多四个，且服从用户设置的并发数；主方案的函数段并行边界保持不变。每个版本拥有独立目录与排版配置，清单采用短文件锁内的读改写，长时间打包与排版不会被登记锁串行化。每个结果单独检查，失败保留已生成文件与诊断，不能将部分成功当作整批完成。

前端多方案窗格使用实际 PDF 的页面渲染，允许风格切换、同页并排比较、播放预览、下载和大屏打开。原生 PPTX 保存淡入、推入或擦除转场；PDF 静态，预览动画属于界面，必须明确区分。用户开启减少动态效果时取消界面动画，仍可正常阅读全部内容。文件树显示风格名称，内部身份只用于精确定位与版本校验。
