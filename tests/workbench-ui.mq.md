工作台数据来自真实生产入口；网络时序来自明确的测试夹具。两种证据不混淆，文件事实、前端交互、模型执行分别验证。

## prepare

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 真实组件、客户端和工作台数据的浏览器夹具 |

此夹具先通过生产生成器建立真实报告、演示和计划，再读取生产工作台投影。复用原有两会话和展开回归，仅在确定性网络响应中加入那份真实 HTML。浏览器仍运行当前产品客户端、官方 WASM 和桥接，工具卡片、工作台、输入栏都是生产组件。

The test substitutes a network observation, not a business callback. The real on_response function must accept a workbench field and update its dedicated region. Later unchanged polls must preserve the expanded execution card. The state replacement has no workbench field, which also exercises the empty legacy snapshot fallback. No fixture writes a passing DOM state or sets the client's last_workbench variable on its behalf.

The source data belongs to a newly created test identity. It does not read a user's conversation, login cookie, private model profile or upload. The office artifacts and completed plan are actual files generated by the deterministic capability suite. Their preview and download links come from the same owner-scoped production renderer.

Only file-mode asset URLs and transport fixtures differ from the deployed page. A screenshot is visual evidence for this fixture and not a claim that a real model ran in the browser. Actual model, database and Docker behavior have their own acceptance workflow. Keeping those claims separate makes each test useful and inspectable.

We **opened = sessions.ensure(id=access(`created`,"value"),principal="agent-capability-acceptance")**.
We **ctx = access(`opened`,"value")**.
We **snapshot = call.invoke(file=(access(`ctx`,"project") + "/pages/agent/artifacts.mq.md"),function="snapshot",arguments=table.put(in=None,at="session",value=access(`ctx`,"id")),root=access(`ctx`,"workspace"),effects="plugin,fs.read")**.
We **_ = composer.prepare(closed=True)**.
We **client = fs.read_text(path=".marqdo/composer-ui.mq.md")**.
We **literal = text.replace(text=json.stringify(value=access(`snapshot`,"html")),old="\x60",new="\\x60")**.
We **anchor = "We **target = \"data:application/json,\" + net.url_encode(text=json.stringify(value=\x60payload\x60)) + \"#route=\""**.
We **addition = "We **payload = table.put(in=\x60payload\x60,at=\"workbench_html\",value=" + `literal` + ")**.\n" + `anchor`**.

We **_ = fs.atomic_write(path=".marqdo/workbench-ui.mq.md",text=`client`)**.

We **_ = fs.atomic_write(path=".marqdo/workbench-ui.html",text=`html`)**.
Return *[保留真实浏览器现场](result.ok(value=".marqdo/workbench-ui.html"))*.

## run

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| chrome | text | required | 已安装 Chromium |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 真实 DOM 的工作台、链接和稳定展开断言 |

Use `chrome`。测试打开专用本地页面，读取真实 DOM 并保存截图。需要同时出现生产计划、DOCX 和 PPTX 文件卡片、预览及下载链接，原来的执行详情也必须仍保持展开。只有浏览器进程零退出不足以通过，缺失任何内容或交互完成标记都会失败。

The screenshot is generated by the actual browser after the current Marqdo client has processed both sessions and their polling responses. It is not an AI mockup or a static hand-drawn replacement for the product. Native component markup and the existing paper-style stylesheet determine layout. The test does not use Python, business JavaScript or an alternate frontend renderer.

The workbench and trace have independent target nodes. This assertion catches a regression where adding delivery UI accidentally replaces the entire conversation and collapses an execution detail. It also catches a renderer producing labels without usable authenticated links. The link itself is not used to bypass OIDC in the fixture; actual owner and foreign-owner downloads are separately tested by the capability suite.

Keep the DOM and screenshot on failure so a broken WASM callback can be distinguished from a missing selector or a layout problem. The browser uses a disposable file page and no personal profile. File access flags are test-only and do not alter the deployed HTTP configuration.
